# Agent-owned Jira connection, runtime-owned safeguards

Add the optional, pointer-neutral `connect` verb: the engineer supplies a board URL and approves one
readable exact summary, rather than driving a configuration CLI or resolving Jira IDs. Dedicated
host agents discover and publish through MCP supplied over ACP, because live tool schemas and Jira
workflows need contextual reasoning rather than a fixed Rust recipe.

Keep Profile, prepare/review/sync and durable receipts as compatible internal tooling. The runtime
retains local-board authority, reviewed authorization, verification proofs, stable bindings and
uncertain-operation reconciliation; agent discretion cannot replace these guards. Coding phase
agents never publish, the Yokai supervisor owns verified state during execution, and credentials
remain in the host store behind the local MCP transport, never in the coding sandbox. Saving a
connection is distinct from proving publication; reconnecting preserves existing remote issues.
